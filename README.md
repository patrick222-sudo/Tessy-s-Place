# Tessy's Place

A modern food ordering platform being developed for Tessy's Place, a Nigerian food brand.

The platform is designed to give customers a convenient way to explore meals, manage their orders, make payments, and receive delivery information while providing administrative tools for managing the food business.

>  This project is currently in development. Features and architecture are still being implemented and refined.
